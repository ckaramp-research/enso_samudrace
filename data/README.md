# Data Directory
This directory contains the lightweight data read by the notebooks in `notebooks/`.
These are derived quantities (indices, metrics, and fits) computed with the analysis code from the SamudrACE control runs, the GFDL-CM4 piControl simulation, ORAS5, ERA5, and the CMIP6 piControl simulations.
`cmip6.json` holds the results of the 37 CMIP6 models, one entry per model, and `obs_bootstrap/` holds the bootstrap ranges of the reanalysis values.
The raw data are available from the sources listed in the top-level README.
